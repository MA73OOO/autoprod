# 🚀 Gemini Video Organizer App (Web App PWA)

Aplicación Web Progresiva (PWA) de nivel profesional para la gestión de proyectos de video, optimización de prompts SEO con Gemini y renderizado automatizado de canales de YouTube.

---

## 📁 Estructura del Proyecto

```text
app_gemini_organizer/
├── docs/
│   ├── Front-End/     <-- Documentación de UI PWA (React / Next.js)
│   ├── Backend/       <-- API Cloud (TypeScript) y Local Helper (Python)
│   ├── Funciones/     <-- Catálogo de funciones (Interceptor de Prompts, BYOK)
│   └── BaseDeDatos/   <-- Esquema Prisma, Supabase y Terraform
├── README.md
└── .gitignore
```

---

## 🛠️ Tecnologías Principales
- **Front-End**: Next.js 15 (App Router), React 19, Tailwind CSS, Shadcn UI, PWA.
- **Backend Cloud**: Next.js API Routes (TypeScript), Prisma ORM, Supabase (PostgreSQL).
- **Agente Helper Local**: Python (FastAPI / PyInstaller) + FFmpeg.
- **Infraestructura**: Terraform IaC + Vercel.
